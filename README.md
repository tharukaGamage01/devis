# Devi Tranquil Villa Website

A modern, responsive website for Devi Tranquil Villa, a luxury villa in Sri Lanka. The site features information about rooms, services, gallery, booking, blog, and contact details.

## Features

- **Responsive Design:** Works on desktop and mobile devices.
- **Pages:** Home, About, Rooms, Services, Gallery, Blog, Book, Contact, FAQ, and custom 404 page.
- **Dynamic Header & Footer:** Shared via HTML includes for consistency.
- **Interactive Elements:** WhatsApp contact, Google Maps embed, sliders, and animations.
- **Modern UI:** Built with Bootstrap, FontAwesome, and custom CSS.
